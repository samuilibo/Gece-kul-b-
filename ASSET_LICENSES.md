# Asset licences

Every asset that ships with NEON CLUB LIVE is listed here. Nothing is downloaded at run time.

## Characters — `public/assets/characters/*.glb`, `face_mask.png`

| Item | Source | Licence |
| --- | --- | --- |
| Base human mesh (HM08), UVs, macro + face morph targets, `game_engine` skeleton and skin weights, MPFB UV-layer masks | MakeHuman / MPFB2 — https://github.com/makehumancommunity/mpfb2 (`src/mpfb/data`, file `LICENSE.ASSETS.md`) | **CC0 1.0** |
| Body shapes of the 8 archetypes (`m1`–`m4`, `f1`–`f4`) | Generated by `tools/build_characters.py` by mixing the CC0 morph targets above | CC0-derived, released by this project under CC0 |
| Clothes (tees, tank tops, long sleeves, hoodie, jacket, vest, trousers, baggy trousers, shorts, leggings, skirt, sneakers, boots), hair styles, hats, glasses, sunglasses, headphones, wrist band | Procedurally generated by `tools/build_characters.py` from the CC0 helper geometry of the base mesh + original code | Original work of this project (MIT, see LICENSE) |
| `face_mask.png` (lips / eyebrows / beard mask) | Baked by `tools/build_characters.py` | Original work (MIT) |
| Skin / eye / hair / clothing colours and the character shader | `src/live/chars/look.ts`, `material.ts` | Original work (MIT) |

No MakeHuman *program code* (AGPL) is included or linked; only the CC0 data files were read at build time.
The MakeHuman "system assets" pack (clothes / hair / skin textures in the separate `makehuman-assets`
repository) was **not** used — it could not be retrieved in the build environment, and the clothes here
are generated instead.

## Animations

All 37 motions (22 dances, 2 group choreographies, duo lead/follow, special, walk, run, sit, wave, jump,
clap, idle and 3 DJ moves) are authored as code in `src/live/chars/dances.ts` and solved with the IK in
`src/live/chars/anim.ts`. No motion-capture or third-party animation data is used. Original work (MIT).

## Music

* **Built-in tracks**: generated live by the original synthesiser in `src/live/audio.ts`
  (patterns, chord progressions, melodies and sounds are original). Original work (MIT). You may stream
  and monetise them.
* **Your files in `music/`**: your responsibility. Only use tracks you hold streaming + commercial rights for.

## Club environment, effects, UI

Geometry, LED/beam shaders, textures (generated on canvases at start-up), particle effects, overlay and
admin UI are original code (MIT). The "NEON CLUB" sign is rendered with the system font.

## YouTube API definition

`server/youtube/proto/stream_list.proto` describes Google's public `liveChatMessages.streamList` gRPC
interface (interface definition published by Google for the YouTube Live Streaming API). It is used only to
call that API. Replace it with Google's official copy if one is published under a different revision.
